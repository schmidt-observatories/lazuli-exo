.. warning::

   This module is **generated** by ``precompute/freeze_targets.py`` from the
   NASA Exoplanet Archive ``PSCompPars`` table. Do not edit it by hand.

too large to reproduce here; ``PLANET_NAMES`` is its sorted key list. Use
:func:`~lazuli_exo.targets.get_target` to read an entry.
