API reference
=============

This reference is generated automatically from the docstrings in the source,
organized by module. The most commonly used objects are re-exported at the top
level of the ``lazuli_exo`` package, so ``lazuli_exo.observe`` and
``lazuli_exo.observe.observe`` both work.

.. note::

   The runtime is terse: several helpers carry no docstring and are
   documented here by signature alone. The narrative explanation of what
   each subsystem computes lives in the :doc:`../user_guide/index`.
